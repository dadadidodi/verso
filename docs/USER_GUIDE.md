# verso 对页使用指南

这是一份带截图的使用指南，适合想快速了解 verso 的读者，也适合准备亲自制作、校对项目的 owner。

本文以本地 Middlemarch 项目为例，截图来自 1440px 宽的本地页面。移动端稍有不同。

## 3 分钟看懂 verso

verso 有三个相关但不同的使用场景：

- **工作台**：本地制作工具。用于上传书籍、创建项目、配对章节、对齐段落和修正错配。
- **阅读模式**：工作台里的预览模式。用于检查最终阅读体验是否顺畅。
- **Reader site**：从项目导出的只读网站。用于分享给其他读者阅读，不包含上传、删除、校对或数据库功能。

verso 的核心阅读方式是：**主要阅读译文，需要时查看对应原文**。

读者不需要一直并排比对两种语言。正常阅读时，原文收在右侧；当某段译文读不顺、拿不准或想确认时，点击译文段落，就能查看对应原文。

最短流程是：

1. 在「校对模式」检查章节配对。
2. 对齐并修正段落对应。
3. 切到「阅读模式」检查阅读效果。
4. 导出只读 Reader site。

## 1. 打开项目

先启动 verso 工作台：

```bash
./run_web.sh
```

打开 [http://localhost:8000](http://localhost:8000)，点顶部「书库」，确认译文书和原文书已经在书库里。然后在「项目」里点击 Middlemarch 项目。

![打开 Middlemarch 项目](assets/user-guide/01-open-project.png)

项目打开后，顶部会显示项目名、章节数和已确认章节数量。右上角可以在「阅读模式」和「校对模式」之间切换。

![项目打开后的阅读模式概览](assets/user-guide/02-read-mode-overview.png)

## 2. 了解阅读模式

「阅读模式」用于预览最终读者的阅读体验。

界面分为三部分：

- 左侧：章节列表。
- 中间：译文正文。
- 右侧：对应原文。

基本操作：

1. 在左侧选择章节。
2. 在中间阅读译文。
3. 点击任意译文段落。
4. 右侧会显示系统匹配到的原文段落和少量上下文。

如果章节已经配对但还没有完成段落对齐，系统会使用近似对应。近似结果只适合快速预览，不适合判断最终效果。要获得更可靠的对应关系，需要回到「校对模式」完成段落对齐。

![阅读模式查看原文](assets/user-guide/08-read-mode-lookup.png)

## 3. 进入校对模式

点击「校对模式」。这是制作和修正对齐结果的主要工作区。

左侧章节列表会显示：

- 译文章节和对应的原文章节。
- 段落对齐状态，例如「未对齐」「待确认」「已确认」。
- 章节配对是否已经锁定。

中间上方是章节配对和当前章段落对齐工具；下方是当前章节的译文和原文区域。

![校对模式工作区](assets/user-guide/03-alignment-mode.png)

## 4. 检查章节配对

章节配对决定「译文第几章」对应「原文第几章」。这是段落对齐之前最重要的一步。

推荐流程：

1. 如果还没有配对，点击「AI 建议配对」。
2. 逐行检查译文章节和原文章节是否对应。
3. 如果某一行不对，直接在右侧下拉框选择正确原文章节。
4. 点击「保存配对草稿」。
5. 确认整体无误后，点击「锁定章节配对」。

配对锁定后，这个面板可以收起；后续主要在左侧章节列表里选一章，再点「对齐本章段落」。

![检查章节配对](assets/user-guide/04-chapter-mapping.png)

## 5. 对齐并检查当前章节

在左侧章节列表选择一章后，查看「当前章段落对齐」面板。

| 按钮 | 作用 |
| --- | --- |
| 对齐本章段落 | 生成或更新当前章的段落对应关系。 |
| 确认本章结果 | 标记当前章已经人工检查，结果基本可靠。 |
| 标记本章跳过 | 当前章不会出现在导出的 Reader site 里。 |
| 重新对齐本章 | 在添加固定对应后，或结果明显不准时，重新生成对齐结果。 |

导出 Reader site 时：

- 「待确认」和「已确认」的章节都会展示。
- 「已跳过」的章节不会展示。

下方阅读区会显示当前章节。左侧是译文，右侧是原文。点击译文段落后，右侧会跳到系统匹配的原文位置。

![检查当前章段落对齐](assets/user-guide/05-alignment-result.png)

## 6. 用固定对应修正错配

如果系统把段落对应错了，可以用「固定对应」手动指定正确关系。

固定对应会告诉系统：这一段或这几段译文，必须对应这一段或这几段原文。之后重新对齐时，系统会保留这些人工指定的关系，只重新计算其他部分。

操作流程：

1. 在「校对模式」里展开左下角「固定对应」面板。
2. 勾选「选择段落」。
3. 在译文区域选择起始段和结束段。
4. 在原文区域选择对应的起始段和结束段。
5. 点击「保存固定对应」。
6. 回到「当前章段落对齐」面板，点击「重新对齐本章」。

![创建固定对应](assets/user-guide/06-anchor-mode.png)

## 7. 批量处理后续章节

当前章检查到一个可接受的程度后，可以继续下一章；如果前面流程已经跑顺，可以用后台任务加快。是否点击「确认本章结果」取决于你是否已经人工认可这一章的对齐质量。

后台任务区有两个常用按钮：

- 「预对齐后 2 章」：适合先小范围试跑，确认策略没问题。
- 「对齐剩余章节」：适合章节配对已经稳定后批量处理。

后台任务列表会显示进度和较早任务摘要。任务运行时可以继续查看已完成章节。

![后台任务](assets/user-guide/07-background-jobs.png)

## 8. 回到阅读模式检查结果

当一章已经对齐，点击右上角「阅读模式」。

检查重点：

- 点击译文段落时，右侧原文是否跳到合理位置。
- 关键段落、长段落、对话段落是否有明显错位。
- 如果发现问题，回到「校对模式」添加「固定对应」，再「重新对齐本章」。
- 如果整体可读，回到「校对模式」点击「确认本章结果」。
- 如果这一章不希望出现在导出的 Reader 里，回到「校对模式」点击「标记本章跳过」。

## 最短工作流

1. 打开项目。
2. 进入「校对模式」。
3. 检查并锁定章节配对。
4. 选一章，点击「对齐本章段落」。
5. 点击译文段落检查原文。
6. 错位时添加「固定对应」，再「重新对齐本章」。
7. 满意后「确认本章结果」。
8. 切回「阅读模式」再读一遍。
